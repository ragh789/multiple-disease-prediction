# multiple-disease-prediction
Developed a machine learning-based system to predict multiple diseases — Kidney, Liver, and Parkinson’s — using patient health data.Integrated multiple datasets and performed extensive data cleaning, feature engineering, and preprocessing to ensure data quality and consistency.Implemented Exploratory Data Analysis (EDA) with histograms, boxplots, and heatmaps to identify trends, correlations, and outliers in medical parameters.Applied feature scaling techniques like StandardScaler to normalize input variables for better model performance.Built and compared classification models (Logistic Regression, Random Forest, and SVM) to identify the best-performing algorithm for each disease.Optimized model accuracy and robustness through hyperparameter tuning and evaluation using confusion matrix, accuracy, precision, recall, and F1-score.
Saved trained models and scalers using joblib, enabling model reuse without retraining.Developed an interactive Streamlit web application allowing users to input medical parameters and predict the likelihood of diseases in real-time.Implemented adjustable decision thresholds in the app for more flexible prediction sensitivity control.Delivered a unified prediction platform integrating three disease models into one application for efficient and user-friendly medical screening.
